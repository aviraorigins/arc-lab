Set up the Series Skill

About 10 minutes, and Claude does most of it. Everything here is public, so you can check it suits your computer before you buy.

What you need

WhatWhat it's for

  1. Get your files

    Right after you pay, Polar emails your receipt with a link to your order page. It gives you two ways to get the skill:

    • The zip, the easiest: click "Series Skill zip" to download it.
    • GitHub, best for updates: connect your free GitHub account and accept the invite to the private arclab-studio/series-skill repository.

    The order page also has the button to join our Discord, where the #help channel is.

  2. Put it where Claude Code finds it

    The skill lives in a folder called arc-lab-series inside your skills folder, with SKILL.md directly inside it:

    Windows   C:\Users\<you>\.claude\skills\arc-lab-series\SKILL.md
Mac       ~/.claude/skills/arc-lab-series/SKILL.md

    With the zip

    Unzip it into your skills folder; the zip already contains the arc-lab-series folder. If there's no skills folder yet, make one.

    • Windows: type %USERPROFILE%\.claude\skills into File Explorer's address bar.
    • Mac: in Finder, choose Go, then Go to Folder, and type ~/.claude/skills. The .claude folder is hidden, so this is the easiest way in.

    With GitHub

    One line. On Windows, in PowerShell:

    git clone https://github.com/arclab-studio/series-skill "$HOME\.claude\skills\arc-lab-series"

    On a Mac, in Terminal:

    git clone https://github.com/arclab-studio/series-skill ~/.claude/skills/arc-lab-series

  3. Let Claude finish the setup

    Make an empty folder for your series, open Claude Code in it, and type:

    set up the Arc Lab series skill

    Claude runs the setup check, tells you what's missing (Node.js, Python, ffmpeg, the drawing library) and installs it with your OK. You're done when it says "ready to make episodes".

  4. Add your voice key

    When Claude makes your series folder, it asks you to paste your ElevenLabs key into a file called .env. You'll find the key at elevenlabs.io, under your profile, in API keys.

    The key stays on your computer. The skill never prints, shares or uploads it.

  5. Make your first episode

    Give Claude your idea in a sentence or two:

    Make me a series: a kid and their robot run a night-shift repair shop, and viewers vote each episode.

    Then you approve three times:

    • The words: the series bible and episode 1's script.
    • The look: the voices, then the characters and sets.
    • The draft: every shot, with captions, sound and an original score, checked frame by frame, including that nothing sits under the app's buttons.

    After your OK, Claude renders the final, makes cover options and writes the post text. Expect a few hours of the computer working for a 30 to 40 second episode, mostly without you. You post it, and the votes decide episode 2.

Getting updates

With GitHub: ask Claude to "update the Arc Lab skill". With the zip: download the new zip from your order page and replace the arc-lab-series folder. Your series live in their own folders, so nothing of yours is lost either way.

If something's stuck

  • Ask Claude to run the Arc Lab setup check. It lists exactly what's missing and how to fix it. You can also run it yourself: 
    python ~/.claude/skills/arc-lab-series/engine/arclab.py doctor
  • Moved the skill folder? Ask Claude to re-link your series to the engine.
  • Your computer feels slow while rendering? Ask Claude to use fewer parallel workers.
